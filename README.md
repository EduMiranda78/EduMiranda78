## Projetos em destaque

### [B3 AI Analyzer](https://github.com/EduMiranda78/b3-ai-analyzer)

Motor de análise técnica para ações e FIIs da B3, com indicadores, histórico, backtest, gerenciamento de risco e camada complementar de IA.

### [VPS Healthcheck](https://github.com/EduMiranda78/vps-healthcheck)

Ferramenta em Bash para auditoria, diagnóstico e inventário de servidores Linux, com relatórios em terminal, TXT, JSON e HTML.

### [Music Reference Lab](https://github.com/EduMiranda78/music-reference-lab)

Aplicação para análise acústica de referências musicais e geração de parâmetros estruturados para ferramentas de áudio com IA.

### [Pedidos de Oração](https://github.com/EduMiranda78/pedido-oracao)

Aplicação Django com PostgreSQL, autenticação, controle de acesso, pesquisa, exportações, PWA e execução em Docker.

### [Mega Sena Master](https://github.com/EduMiranda78/mega-sena)

Aplicação Flask para validação de históricos, análise estatística de frequências e geração de combinações.

### [Agente Jurídico](https://github.com/EduMiranda78/AgenteJuridicoDeCorrecao)

Aplicação FastAPI para revisão estruturada de contratos com apoio de IA, controles de segurança e validação humana.

### [Meu Treino](https://treino.mirandastack.com/)

Aplicação web para planejamento e execução de treinos, acompanhamento de sessões, histórico e análise de evolução.
